Overview

The first version stays intentionally small. Agents can publish polished plans and reports without opening a bespoke deploy loop, while the service keeps scripts, forms, embeds, and local-file tricks out of draft uploads.

Visibility model

Upload access is private. Draft view URLs are public and unlisted. Treat every uploaded draft as link-viewable until viewer auth is added later.

Publishing Flow

Write HTML → Validate → Upload → Review Link 
npx patchpage validate ./plan.html
npx patchpage upload ./plan.html

Build Checks

1 Safe static document Done

The draft is one complete HTML document with inline CSS and no JavaScript, forms, iframes, external fonts, or external design assets.

  • Semantic headings and readable body copy
  • Patchy paper, grid, ink borders, and hard shadows
  • No blocked tags or unsafe URL schemes
Risk: leaking sensitive content Rollback: delete or disable the draft

2 Portable host Live

The default Patchy deployment runs at post.patchyhq.com, but the CLI can target a self-hosted PatchPage service with --api-url or PATCHPAGE_API_URL.

Owner: deployer Rollback: point the CLI back at the previous host
