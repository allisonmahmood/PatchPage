One file, one review link

PatchPage turns plans, briefs, architecture notes, and reports into durable single-file HTML artifacts. The service rejects active content such as scripts, forms, embeds, and unsafe URL schemes before storing the document.

Public by link

Draft viewer URLs are public and unlisted. Anyone with the link can open the rendered artifact, so publish only material that is safe to share with every link holder.

Publish from a server you control

Requires Node.js 22 or newer. Provide PATCHPAGE_SETUP_TOKEN through a secret environment. The scoped flow pins the self-hosted origin, clears inherited credential overrides, and verifies the stored token before validation or upload.

Write HTML → Configure → Verify → Validate → Upload → Share Link 
(
  set +x
  set -eu
  PATCHPAGE_API_URL='https://patchpage.example.com'
  export PATCHPAGE_API_URL
  unset PATCHPAGE_API_TOKEN
  unset TOKEN
  : "${PATCHPAGE_SETUP_TOKEN:?Set PATCHPAGE_SETUP_TOKEN to a PatchPage API token}"
  ARTIFACT_PATH='./plan.html'

  printf '%s' "$PATCHPAGE_SETUP_TOKEN" | npx --yes patchpage auth set --token-stdin --api-url "$PATCHPAGE_API_URL"
  unset PATCHPAGE_SETUP_TOKEN
  npx --yes patchpage whoami &&
    npx --yes patchpage validate "$ARTIFACT_PATH" &&
    npx --yes patchpage upload "$ARTIFACT_PATH"
)
About the hosted default

The CLI defaults to https://post.patchyhq.com. This is the maintainer's private instance: it has no public token signup and issues no tokens to outside callers.

Access is explicit

1 Token-authenticated publishing Required

Every upload requires a bearer API token, on every configuration. A self-hosted server rejects a request that carries no token with 401, and a present but invalid token stays 401. Authenticated uploads create drafts and update drafts the publisher owns; uploading the same known file updates its cached draft unless --new is passed.

Surface Current behavior What it means
Authenticated upload Token required Create new drafts or update drafts owned by the publisher.
Upload without a token Rejected with 401 Retired posture; no server setting restores it.
Draft URL Public and unlisted Anyone with the link can open the artifact without an account.
Viewer Sandboxed frame The uploaded artifact is isolated from the PatchPage wrapper.

The artifact contract

2 Safe, portable HTML Ready

Each upload is one complete HTML document with inline CSS and no JavaScript, forms, iframes, external fonts, or external design assets.

  • Semantic headings and readable body copy
  • Responsive layout and visible keyboard focus
  • No blocked tags, secrets, or unsafe URL schemes
